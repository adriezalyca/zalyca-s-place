# zalyca-s-place
# Sistem Pencatatan Hasil Panen Digital

Proyek ini adalah aplikasi Python sederhana untuk menghitung total hasil panen komoditas pertanian dan potongan harga (diskon) penjualan.

## Fitur Utama
- Mengakulasi total berat hasil panen.
- Menghitung diskon penjualan otomatis.

## Cara Menjalankan Program
Jalankan perintah berikut di terminal atau Google Colab:
python main.py
